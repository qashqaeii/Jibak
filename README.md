# جیبیک | Jibik 🦊

دستیار مدیریت مالی شخصی و خانوادگی با زبان بصری فارسی و راست‌به‌چپ، ساخته‌شده با **Kotlin + Jetpack Compose**.

> **وضعیت فعلی: پیش‌نمونهٔ درحال توسعه (Pre-alpha).** کد اولیه روی مخزن ثبت شده است، اما تا زمان موفقیت CI و تست روی دستگاه، نسخه قابل نصب یا آماده انتشار اعلام نمی‌شود.

## امکانات فعلی پیش‌نمونه

- صفحه خوش‌آمدگویی جیبو (فعلاً با نماد موقت؛ تصویر اصلی هنوز درون APK قرار نگرفته است)
- داشبورد سبز/کرم/نارنجی، درآمد و هزینه، تاریخچه و سقف بودجه
- ثبت درآمد و هزینه و نگه‌داری آن‌ها روی همان دستگاه، بدون اینترنت
- ماژول محاسبات مالی با واحد صحیح «تومان» و تست انتقال و دوباره‌شماری
- GitHub Actions برای تست ماژول مالی و ساخت APK نسخه Debug

**هشدار:** ذخیره‌سازی آزمایشی SharedPreferences جایگزین Room رمزنگاری‌شده و همگام‌سازی امن نیست. از داده حساس واقعی استفاده نکنید.

## ساخت و تست

در محیطی با JDK 17، Android SDK API 36 و Gradle 8.13:

```bash
gradle :core:finance:test :app:assembleDebug
```

[اجرای خودکار GitHub Actions](https://github.com/qashqaeii/Jibak/actions) پس از هر Push روی `main` اجرا می‌شود. اگر Workflow موفق شود، فایل **Jibik-debug-apk** از بخش Artifacts آن اجرا دریافت می‌شود. وجود Workflow به‌تنهایی تأیید موفقیت بیلد یا وجود APK نیست.
