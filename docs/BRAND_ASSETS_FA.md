# هویت تصویری جیبیک — دارایی‌های اپ

- **لوگوی بدون پس‌زمینه:** `app/src/main/res/drawable-nodpi/jibik_logo.webp`، خروجی WebP شفاف از تصویر اختصاصی جیبو (۱۹۲×۱۹۲، حدود ۶ کیلوبایت).
- **شخصیت تمام‌قد جیبو:** `app/src/main/res/drawable-nodpi/jibo_welcome.webp` برای خوش‌آمدگویی و صفحات خالی.
- **لانچر:** `app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml` با رنگ پس‌زمینه مجزای کرم برای نیاز Android Adaptive Icon؛ خود فایل WebP شفاف است. پس‌زمینه لانچر با پس‌زمینه تصویر لوگو اشتباه گرفته نشود.
- **سیاست سایر تصاویر:** همیشه transparent WebP و بدون کادر/بک‌گراند baked-in؛ برای کارت‌های مالی از Compose gradient، شکل و typography استفاده شود، نه raster UI.
- اندازه و فشرده‌سازی تصاویر متناسب با محل نمایش و با آزمون بصری در دستگاه نهایی شود. برای آیکون مارکت و منابع رسمی سایزهای بالاتر جداگانه نیاز است.
